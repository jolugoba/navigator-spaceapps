# NAVIGATOR 2.0 — NASA Space Apps Challenge 2026

Juego multijugador de misiones espaciales en realidad aumentada: diseñas la nave (motor, energía, antena,
instrumentos, presupuesto), la lanzas, la pilotas con asistencias gravitatorias reales y operas la ciencia en el planeta.

| Carpeta | Qué es |
|---|---|
| [`flutter_app/`](flutter_app/README.md) | **La app que se instala** (Flutter). Contiene el juego de Unity embebido. |
| [`unity_project/NavigatorUnity/`](NAVIGATOR_UNITY_QUICKSTART.md) | El juego (Unity 6, URP). |
| `lib/`, `android/`, `ios/` (raíz) | Versión Flutter anterior (filament_scene). Solo referencia: no compila sola. |
